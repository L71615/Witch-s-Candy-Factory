# Contra submission copy

## Short description

**Witch's Candy Factory: Moonlight Dash** is a 90-second illustrated action
runner built with Rive CLI, RML, and Luau. Play as Mira, the factory's last
courier, and carry the final Moon Spark through three fully changing chapters:
moonlit rooftops, a teal-and-copper cursed factory, and a three-phase duel with
the Hungry Cauldron.

Jump and double-jump over cursed candy, flip beneath the bridge, chain three
sugar-blade cuts, and use a perfectly timed broom dash to survive. The final
boss uses high-contrast electric-cyan and violet attack language, breakable
guards, an exposed core, and an enraged final phase. Live rank, guild pace,
combo, no-hit, and clear-time bonuses make every run competitive.

## Feature used

**Rive CLI** — the project uses generated RML for the complete visual scene and
Luau for movement, collision, input buffering, combat, scoring, adaptive audio,
chapter transitions, and boss behavior.
